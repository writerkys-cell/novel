# 세 앱

소설 쓰는 일을 세 자리로 나눈 것입니다.

| 폴더 | 앱 | 하는 일 |
|---|---|---|
| `groundwork/` | **밑작업** | 이야기에 대해 알게 된 것을 조각으로 쌓고, 클로드에게 정리를 받는다 |
| `2667/` | **2667** | 정리된 것으로 뼈대·인물·단위를 잡고 씬을 뽑는다 |
| `pocket/` | **주머니** | 아이폰에서 짧게 담는다. 한 번 내보내면 밑작업의 조각 하나가 된다 |

자료는 모두 각자의 브라우저 안에만 있습니다. 어디로도 보내지 않습니다.

---

## 1. 올리기

1. 깃허브에서 저장소를 하나 만듭니다. 이름은 무엇이든 좋습니다.
2. 이 폴더 안의 것을 **통째로** 그 저장소에 올립니다. (`.gitignore`도 함께)
3. 저장소의 **Settings → Pages**로 갑니다.
4. Source를 `Deploy from a branch`, 브랜치를 `main`, 폴더를 `/ (root)`로 두고 저장합니다.
5. 1~2분 뒤 주소가 생깁니다.

주소는 이렇게 됩니다.

```
https://아이디.github.io/저장소이름/groundwork/
https://아이디.github.io/저장소이름/2667/
https://아이디.github.io/저장소이름/pocket/
```

이 주소를 스크리브너의 문서 링크나 프로젝트 북마크에 걸어 두시면 됩니다.

## 2. 앱으로 설치하기 (맥)

주소를 크롬에서 연 뒤, 백업 탭의 **「앱으로 설치」**를 누르거나 주소창 오른쪽의 설치 아이콘을 누릅니다. 독에 아이콘이 생기고 별도 창으로 열립니다. 설치해 두시면 스크리브너에서 링크를 눌러도 그 창으로 가므로, 창이 두 개 생기는 일이 줄어듭니다.

## 3. 앱으로 두기 (아이폰)

`pocket/` 주소를 사파리로 연 뒤 공유 버튼 → **홈 화면에 추가**. 이렇게 두셔야 저장한 것이 안전합니다.

## 4. 파일에 연결하기 (맥, 권장)

밑작업과 2667의 **백업 탭 → 저장소 → 「파일에 연결」**을 누르고, 아이클라우드 드라이브 안의 아무 폴더에 `밑작업.json`, `2667.json`을 만들어 지정하세요.

그 뒤로는 저장할 때마다 그 파일에도 함께 적힙니다. 브라우저 자료가 다 지워져도 **「파일에서 되살리기」**로 돌아옵니다. 이 파일들은 **깃허브 저장소 폴더가 아닌 곳**에 두세요.

## 5. 조심할 것

- 앱에서 내보낸 `.json` 백업 파일을 이 저장소 폴더에 넣지 마세요. 소설이 통째로 공개됩니다. `.gitignore`가 막아주지만, 애초에 다른 곳에 두시는 편이 낫습니다.
- 크롬에서 「인터넷 사용 기록 삭제」로 사이트 데이터를 지우면 세 앱의 자료가 한꺼번에 사라집니다. 4번의 파일 연결이 그 대비입니다.

## 새 판을 올릴 때

앱 파일을 고쳐 다시 올리실 때는, **고친 앱 폴더의 `sw.js` 첫 줄**에 있는

```js
const VERSION='2026-08-07a';
```

이 날짜를 오늘 날짜로 바꾸어 함께 올려 주세요. 그래야 앱이 화면 위에 「새 판이 올라왔습니다」라고 알려줍니다. 이걸 잊으면 고친 것이 한동안 반영되지 않습니다.

지금 판: **2026-08-07a**

## 폴더

```
├── .gitignore
├── README.md
├── 2667/
│   ├── index.html            앱
│   ├── shell.js              오프라인·창 잠금·파일 연결
│   ├── sw.js                 ← 새 판을 올릴 때 VERSION을 고칩니다
│   ├── manifest.webmanifest  앱으로 설치되기 위한 설명
│   └── icon-*.png            아이콘
├── groundwork/   (같은 구성)
└── pocket/       (같은 구성)
```

`shell.js`는 세 폴더에 같은 내용이 들어 있습니다. 고칠 일이 생기면 세 개를 함께 바꾸어야 합니다.
